## 🔍 How OLLAMA Extraction Works

1. **PDF Upload** → User uploads research paper via frontend

2. **Text Extraction** → extraction_service.py
   - Reads PDF with PyMuPDF
   - Extracts text from all pages
   - Splits into sections (Introduction, Methods, Results, etc.)

3. **Agent Processing** → agent_service.py + ollama_service.py
   - Mechanical Properties Agent
     * Extracts yield strength, tensile strength, elongation, grain size
     * Uses Results and Methods sections
   
   - Composition Agent
     * Extracts alloy compositions
     * Identifies elements and percentages
     * Uses Introduction and Materials sections
   
   - Processing Agent
     * Extracts processing temperatures, durations, techniques
     * Identifies casting, rolling, annealing steps
     * Uses Methods section
   
   - Microstructure Agent
     * Extracts grain size, texture, recrystallization status
     * Identifies morphology and crystal structure
     * Uses Results section

4. **Storage** → MongoDB Atlas
   - Results collection: Stores extracted data
   - Jobs collection: Stores job metadata

5. **Retrieval** → Frontend
   - Frontend queries /api/v1/results/{job_id}
   - Backend retrieves from MongoDB
   - Display to user

## ⚠️ Troubleshooting

### Issue: "OLLAMA not available"
**Solution:**
1. Check OLLAMA is running: `curl http://localhost:11435`
2. Check port in .env: `OLLAMA_HOST=http://localhost:11435`
3. Start OLLAMA: `ollama serve`

### Issue: "Model not found"
**Solution:**
1. Check available models: `ollama list`
2. Pull model: `ollama pull mistral`
3. Update .env: `OLLAMA_MODEL=mistral`

### Issue: "MongoDB connection failed"
**Solution:**
1. Add your IP to MongoDB Atlas whitelist
2. Verify connection string in .env
3. Test: `python backend/test_mongodb_atlas.py`

### Issue: "Extraction returns mock data"
**Possible reasons:**
1. OLLAMA is not responding
2. Network timeout between backend and OLLAMA
3. OLLAMA model not loaded

**Solution:**
1. Check logs: `backend/logs/`
2. Verify OLLAMA: `curl http://localhost:11435/api/tags`
3. Restart OLLAMA: `ollama serve`
