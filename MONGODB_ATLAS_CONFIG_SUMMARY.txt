┃ DATA FLOW IN MONGODB ATLAS                                              ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

  When User Uploads PDF:
  
  1. Frontend sends PDF to: /upload endpoint
  2. Backend creates Job
     → Saves to MongoDB Atlas "jobs" collection (Status: pending)
  3. Backend extracts text (ExtractionService)
  4. Backend runs Agents (AgentService)
     → Calls Ollama for LLM processing
  5. Backend validates results (ValidationService)
     → Links evidence to source text
  6. Backend saves final results
     → Saves to MongoDB Atlas "results" collection
  7. Frontend retrieves & displays results: /results/{job_id}
     → All data comes from MongoDB Atlas

  MongoDB Collections:
    ├─ jobs: Job status, progress, metadata
    ├─ results: Extracted data, validation scores, evidence
    └─ metadata: System information, statistics

  Cause: Dependencies not installed
